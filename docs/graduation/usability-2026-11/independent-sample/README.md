# 独立评论样本 · 人工复标材料包

生成日期：2026年11月20日
用途：兑现任务书「补充独立评论样本和人工标注复核」承诺；第 12-14 周执行
诚实声明：样本为**合成模拟评论**（非真实采集），"独立"指未参与前期开发与首轮标注，不构成真实市场数据。

## 文件清单

| 文件 | 内容 |
|---|---|
| `independent-reviews.csv` | 40 条独立评论（r077–r116），CSV 格式与主样本同构，可直接走产品导入流程 |
| `ai-initial-labels.json` | AI 初标（revision: independent-2026-11-20-r1，source=codex_pending，**未经用户确认**） |
| `Mercata-Lens_独立样本复标工作簿_2026-11-20.xlsx` | 人工复标工作簿（50 行标注 × 13 列），含判定口径 sheet |

## 样本构成（40 条）

| 类别 | 数量 | 考察点 |
|---|---|---|
| 主题清晰·负面 | 15 | 单主题单情感的基础判定 |
| 主题清晰·正面 | 9 | 正面判定（防"只找问题"偏差） |
| 多主题混合情感 | 6 | 同评论正负并存，须分别保留、不得合成中性 |
| 目录未覆盖 | 4 | 运输/App/客服/插头——考察"不硬塞标签" |
| 反向表述防误标 | 2 | "Not hard to clean"、"Zero noise"——否定结构 |
| 补充主题 | 4 | 滤芯碳尘/配件运费/中性补水/分时间情感 |

标签目录：19 个主题全部用到；越界标签 0。

## 复核流程（薛雅利执行，约 2-3 小时）

1. 打开 xlsx「人工复标表」，逐行看：原文 → AI 初标 → 证据
2. 在「人工判定」列选：正确 / 主题错 / 情感错 / 证据错 / 漏标 / 不应标注
3. 判定不是"正确"时，填修正主题/情感 + **理由必填**
4. 「目录未覆盖」4 条（r105–r108）：AI 已留空，确认并注明"目录未覆盖"即可
5. 特别注意 2 条反向表述（r115、r116）和 6 条混合情感——这是本批的考察重点
6. 全部 50 行判定 + 理由非空 = 复标完成

## 完成后的产出（我来做）

- 一致率统计：主题一致率 / 情感一致率 / 证据支持率（分项 + 总体）
- 分歧明细表：每处不一致的错误类型归类
- 写入阶段总结与论文「标注质量评估」小节

## 与现有数据的边界

- 独立样本不混入 `public/demo/reviews.csv`（主样本保持 76 条不变）；
- 复标完成后可作为模型对比评测的**留出集**（未参与开发的数据），这正是"独立"的价值；
- 论文表述口径：「补充 40 条独立合成评论并完成人工复核，用于评估标注一致性；样本为模拟数据，不构成真实市场验证。」
