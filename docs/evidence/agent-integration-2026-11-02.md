## 三轮与纠错测试的证据级别
浏览器测试使用显式transport stub连续三轮回复。确认历史消息长度为0、2、4，研究revision保持相同。随后手动纠错，在新一轮请求中确认旧历史清空、revision变化、修正标签进入上下文。
这是会话与界面契约验证，不是真实大模型对话、语义质量、供应商可用性、调用成功率或延迟评测。测试替身仅位于测试文件，不作为产品降级回答。

## 已修复的问题
1. 请求体途中断开导致异步流错误未捕获：新增断连测试复现后，捕获中断并确保服务仍可响应状态请求。请求体按Buffer统一UTF-8解码。
2. 自定义前端端口被固定Origin白名单误拦：网关读取PORT，Vite使用strictPort避免静默换端口；两端须使用相同PORT。
3. 导航装饰Open进入链接无障碍名称，导致原有浏览器测试完整名称定位失败：为导航设置清楚的双语aria-label，保留原有测试断言，回归通过。
4. 纠错移除旧引用按钮后无法返回焦点：回退到输入框；补充保存原因显示、过期用户问题文案与页签方向键操作。

## 局限与未完成项
- 未注册模型账号、未创建密钥、未产生外部或付费模型请求。具体供应商兼容性待验证，配置完整只表示允许调用，不表示已验证服务可用。
- 网关支持约定的chat-completions形状，不自动适配所有供应商。仅配置接口不能算真实接入验收完成。
- 引用存在性、字段、长度、数字与部分越界表述校验不等于语义归因正确或杜绝幻觉。仍需人工抽查与真实模型评估，不能报告标签准确率。
- 不支持上传数据模型分析、持久化、生产部署或自主六状态工具编排；研究助手离开路由后会话丢失，纠错保留范围仍为当前研究会话。
- 模型answer限制普通数字，以确定性统计区提供数量；这一限制可能导致部分真实供应商返回被拒绝，需要在后续真实评估中调整契约，而非移除证据边界。
- 代码册与≥30%注释率未在本批核验，课程要求的真人调研、互评、教师验收和真实三轮模型验证仍未完成。
