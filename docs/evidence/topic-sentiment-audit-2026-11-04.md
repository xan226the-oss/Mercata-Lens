# 多主题情感审核口径
用户于2026年11月4日同意将主题与正负中分开，并支持一条评论多个标签。本轮更新的是人工审核材料，平台现有问题规则未自动迁移。

## 数据单位
每个条目为：评论ID、体验主题、情感倾向、支持片段或情境、审核人、审核日期。
同一评论允许多个条目。主题使用中性名称：清洁体验、声音表现、密封防漏、水泵可靠性、滤芯维护与成本、容量与补水、宠物接受度、其他。
情感倾向为正面、负面、中性。正负同时存在不能视为中性；不同主题分别记录，同一主题在不同条件下有褒贬时也可拆两条，并说明情境。无法判断先留空并记录疑问。
