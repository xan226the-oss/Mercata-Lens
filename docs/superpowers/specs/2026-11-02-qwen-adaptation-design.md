# Qwen非思考输出适配设计
用户授权：保持平台功能不变，免费额度用完即停，继续完成测试与报告。
问题：默认思考配置超时多；关闭思考后常把编号写入answer，结构校验拒绝；存在臆造批次描述。
方案比较：仅延长超时不能解决速度；移除数字校验会损害边界；采用显式Qwen非思考JSON配置及字段示例，维持校验，是本轮选择。
配置：新增MODEL_PROFILE=qwen-json-nonthinking，默认空为通用配置。仅百炼可信HTTPS域名及qwen模型可启用；未知配置禁用调用。profile请求enable_thinking=false、response_format=json_object、max_completion_tokens=1024。提示词区分原文事实与假设，编号只出现在reviewIds；无来源、销量、批次元数据时明确未知。不能以提示词或JSON保证语义可靠。
评测：原12任务两遍，先单条，再整批；每条输出进度并落盘，记录配置与失败输出的安全摘要/原因。HTTP拒绝立即停止本批，不重试；不改变前端功能。所有数据仅内置模拟评论。
验收：自动回归通过；真实调用至少一组完整三轮，复核所有成功内容；不满足则如实记失败，不放宽校验追求通过率。独立代码复核后提交；报告区分结构通过、语义辅助审阅和独立人工验收。

实施补充：真实评测表明来源/经营边界问答不能强行引用评论。新增两个白名单scopeNotice，由服务端替换共享固定文字、前端要求canonical文字并标系统说明；无引用的任意模型解释仍拒绝。JSON模式采用json_object，不宣称Schema语义约束。逐条进度、错误停止及metadata白名单已实现并获独立复核APPROVED。
