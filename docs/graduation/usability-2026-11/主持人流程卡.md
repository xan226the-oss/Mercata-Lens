# 主持人流程卡（单场测试 20 分钟）

> 打印一张随身用。原则：**工具在被测，不是人；全程零提示。**

## 时间轴

```
0:00-2:00   开场
2:00-5:00   T1 熟悉与定位
5:00-10:00  T2 痛点核验
10:00-15:00 T3 提问与引用（模型就绪时）
15:00-20:00 T4 纠错失效 + T5 判断导出
（若含 SUS + 访谈，整场延至 25-28 分钟）
```

## 开场白（照念）

「谢谢你参加。我们测试的是一个跨境电商选品研究工具。今天要说明三件事：
1. **测的是工具，不是你**——遇到困难说明工具要改进，不是你的问题；
2. 产品里全部是**模拟演示数据**，不是真实市场数据；
3. 请**边操作边说出你在想什么**，这对我最有价值。过程大约 20 分钟，可以随时暂停。准备好了我们就开始。」

## 各任务引导话术（念完就闭嘴）

- **T1**「这是一个帮你研究美国市场宠物饮水机选品的工具。请找到：目前数据里有多少商品、多少评论？数据是真实的还是演示的？」
- **T2**「你想知道用户抱怨最多的问题。进入痛点页面，找一条『清洁困难』的评论，点开它的原文证据，告诉我标签和原文一致吗？」
- **T3**「在研究助手页，向助手提问：『这批样本里有哪些清洗相关的问题？』回答出现后，点击引用按钮，确认跳到了对应评论原文。」
- **T4**「假设你认为某条评论标签不对。在证据区把它的某个主题标签改成中性，填原因保存。然后观察：之前的助手回答有什么变化？」
- **T5**「最后，进入决策页面，查看系统给出的判断，并把本次研究记录下载保存。」

## 卡住 3 分钟时唯一可用的话术

「要不要一点提示？」→ 用户点头后给**最小**提示，并在表上记"协助"。

## 禁语清单

- ❌「你应该点左边那个」
- ❌「这里，证据抽屉」
- ❌「对/不对」（改用「嗯」「明白了」）
- ❌ 提前解释"旧解释失效"机制

## 收尾（3 分钟）

「最后一个任务完成了，问三个问题：
1. 哪一步最让你困惑？
2. 看到『证据原文』对你判断问题有没有帮助？
3. 你会信任这个工具给的结论吗？为什么？」

然后请填写 SUS 问卷（10 题，2 分钟），**不要解释题目**。

## 结束语

「测试完成，非常感谢！你的反馈会直接用于改进。如果对产品有兴趣，正式版我可以再演示。」

## 主持人自检（每场结束后立刻填）

- [ ] 录屏文件已保存并按 `U{编号}-{日期}` 命名
- [ ] 记录表备注栏有用户原话
- [ ] 协助次数已如实标注（不许美化）
- [ ] SUS 已收回
